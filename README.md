# House Price Prediction

This project focuses on predicting housing prices using machine learning techniques. It uses popular Python libraries such as NumPy, Pandas, Scikit-learn, Matplotlib, Seaborn, and XGBoost to build an end-to-end price prediction model.

## Project Overview

The goal of this project is to develop a regression model that can predict house prices based on different features like income, house age, number of rooms, and population. This helps in understanding how different factors affect housing prices.

## Key Features

- Data loading using the California Housing dataset  
- Data preprocessing using Pandas  
- Data visualization using Matplotlib and Seaborn  
- Train-test split for model validation  
- Regression model using XGBoost  
- Model evaluation using R² Score and Mean Absolute Error  

## How to Run

1. Clone the repository  
2. Install required libraries  
3. Open the notebook file and run all cells
